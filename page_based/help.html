1. Searching

One box, four releases, 2,713 entries. The query language is small and exact.

You typeYou getExample
word1 word2entries containing bothZika funding
word1|word2entries containing eitherZika|Ebola
lab*prefix matchvacc*
"exact phrase"that phrase, in order"redacted pages"

Case is ignored unless Aa case sensitive is ticked. Every hit is highlighted; HIT Prev/Next steps through matches inside an entry and moves the PDF to each hit.

2. Boxes: diary, email, attachment, note

Every result is one box. The box type decides the badge and where it sits.

KindMeaningBadge
diarya diary daynone — the common case stays quiet
emailone message, one author, one timestampkind chip + source badge
attachmenta document travelling with a messageindented box under its parent
notepublisher material about the releaserelease-note box, off the timeline

An email box holds only what its author wrote — no quoted history. The messages it answers are separate boxes, reached through reply links. Attachments announced in the text show as chips: an active link when the document is in the releases, a dimmed tag otherwise.

Every box scrolls on its own; Full text removes the height cap. Email stamps are normalised to New York time, local time alongside.

3. The timeline

The dual timeline plots entries (left) against search hits (right). Clicking a bar opens that day's entry and its PDF page. Box types ticks which kinds are listed.

4. The PDF viewer

Clicking a result switches to that entry's release PDF automatically and jumps to the page where its content starts; HIT Prev/Next follows each hit across pages.

5. Bookmarks

The rail on the left keeps your own pointers into the record. Click the toggle on any box to keep it; click again to drop it. Save writes a JSON file you can keep or load into another DRASTIC app.

8. Release notes

Missing Years + bookmarks + manual

  • Missing Years release: 694 diary entries Jul 2015 – Dec 2019 plus the publisher's cover analysis as a release note; every entry page-mapped with content-equality asserted.
  • Bookmarks rail: collapsible sidebar with scroll arrows, a toggle on every box, and Save/Load to a JSON file that travels between the DRASTIC apps.
  • On-demand PDF rendering: clicking a result always lands on the correct release.

9. Known limits

  • Inline pasted emails inside diary prose stay inside the diary box by design.
  • Redacted pages carry only the release footer; Mar 9–10 2016 have no diary text here.
  • Year typos corrected from sequence + content carry a note on the card — never silent.

Sources: the Congressional releases of Chairman Rand Paul (Senate reading room).
